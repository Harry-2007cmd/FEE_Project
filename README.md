# FlexForm Gym Website

A responsive fitness landing page and dashboard built with HTML, CSS, and JavaScript. The project includes membership plans, workout programs, BMI and calorie calculators, class schedule filters, trainer cards, contact form, and dashboard tracking tools.

## Features

- Modern responsive landing page
- Dark/light mode toggle
- Membership selection with localStorage
- Workout program filtering
- BMI and calorie calculators
- Trainer and class schedule sections
- Registration and contact validation
- Dashboard tools for tracking workouts, water, timer, and progress
- Search and FAQ interactions
- Modal membership details and smooth scroll

## Run locally

Open the folder in a browser, or use a simple static server:

```bash
cd d:\fee2(1)
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — page structure and sections
- `style.css` — responsive styling and layout
- `script.js` — interactive logic and localStorage features
